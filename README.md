# NEWCRM | TinTAi - CRM

Construção pública de um CRM a partir de um exemplo fictício: TinTAi, um pintor autônomo que precisa acompanhar atendimentos, agenda de serviços e fluxo de caixa. Nenhum dado real de cliente é usado no exemplo.

A série mostra como uma ideia vira produto pelo método **MAPA**: **Motivo, Arquitetura, Pesquisa e Ação**. O [cronograma das aulas](cronograma.md) apresenta a sequência de temas, sem datas de estreia ou promessa de funcionalidades prontas.

Depois de cada gravação, o registro da aula será acrescentado ao repositório com o que foi feito, as decisões tomadas, os testes e os arquivos produzidos. Até lá, os temas do cronograma são apenas o percurso de aprendizagem.
