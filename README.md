# TinTAi - CRM

Construção pública de um CRM, documentada em série no Instagram [@marcelogoncalves.ofc](https://www.instagram.com/marcelogoncalves.ofc/).

Exemplo condutor: TinTAi, um pintor profissional autônomo fictício, criado para ensinar. Nenhum dado real de cliente é usado neste projeto.

## Planejamento

Toda a documentação de planejamento está em [`planejamento/`](planejamento/):

- `briefing.md`: visão geral da série e do projeto.
- `bloco-01-pensar.md` a `bloco-08-evoluir-com-evidencias.md`: os 8 blocos da trilha, do problema à evolução com evidências.
- `registro-da-trilha.md`: histórico de decisões, com data, motivo e evidência.
- `plano-de-producao.md` (e a versão navegável em `plano-de-producao.html`): guia de execução fase a fase.

O código do CRM em si ainda não foi construído. Este repositório começa pela documentação do raciocínio, conforme a Fase 2 do plano de produção.
